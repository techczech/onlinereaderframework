# Evidence digest-map serialisation

The normal pre-commit scanner flagged fourteen SHA-256 map entries as generic API keys. Redacted scanner locations are retained. Every flagged value was verified to be a 64-character hexadecimal file digest. Four evidence JSON documents were reserialised using explicit path/digest columns: any all-digest map becomes {format: file-digests-v1, entries: [{path, digest}]}. The transformation is recursive and reversible. Restoring every converted document reproduces its original parsed value exactly; before/after byte hashes and round-trip proofs are retained in evidence-digest-serialization.json. No check result, source hash, finding, command output or production source was changed. Original byte-level signatures of those JSON files are historical; the semantic evidence is intact. This is the same explicit-column formatting used for the prior private reader release, with no scanner suppression or hook bypass.
