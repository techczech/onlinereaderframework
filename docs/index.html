Online Reader Framework

A React library that turns a book, guide or long manual into a web edition that is comfortable to read. You supply the book as data. The framework supplies the reader.

What it does

Long texts are hard to read on a screen. The reader gives each book the same set of tools, so the reader of the book can adjust the page to how they read.

  • Navigate

    A nested contents tree, previous and next links, six front-page layouts, and an address for every section.

  • Search

    Full-text search across every section, including nested ones.

  • Adjust the page

    Light, dark or system theme. Font, size, spacing and text width. Dim the other paragraphs, show a few lines, or lay a ruler under the current line. Optional anchored reading emphasises the first letters of words.

  • Keep notes

    Highlights with notes, reflections, bookmarks and progress, saved in the reader's own browser for each book. Notes export as Markdown, and a quote can become an image with a QR code.

  • Listen

    Read aloud with the browser's speech voices, with the spoken passage highlighted. A host can also supply audio tracks, with optional word alignment.

  • Take it away

    Build an EPUB 3 file of the book in the browser. Generate Markdown files and a prompt so that a reader can ask an AI agent about the book.

The reader has no server and no accounts, and it calls no AI service. A host can add its own coaching panel through one render function. Read aloud depends on the voices the browser provides, and EPUB export needs a browser.

Live editions

    All 253 answers the author wrote on Linguistics Stack Exchange between 2013 and 2016, in nine sections.

Get started

You need Node 22 or later. The package is used from source and is not on npm.

git clone https://github.com/techczech/onlinereaderframework.git
cd onlinereaderframework
npm run setup
npm run build
npm test

Then install the built packages/reader-core folder in your project as a local file dependency, and pass the reader a book:

import { PublicationReader } from 'reader-core';
import 'reader-core/reader.css';

const book = {
  id: 'my-guide',
  title: 'My Guide',
  author: 'A. Author',
  description: 'One sentence about the book.',
  sections: [
    { id: 'start', title: 'Start here', category: 'Basics',
      content: '# Start here\n\nSome **Markdown**.' },
  ],
};

export default () => <PublicationReader book={book} />;

The README covers the book format in full, agent-file generation, EPUB export and the limits of this release.

Reading research behind it

The reading settings follow guidance the author has published on how people read and what makes text easy to process. Both guides are free to read.

  • Foundations of Readability: five principles for readable documents and slides, and three reading modes (comprehensive reading, skimming and scanning).
  • Principles of Readability: clear-writing principles, with examples and checklists.
  • Academic Reading Framework: a framework for improving academic reading productivity.
