# Reader correction closure

**Both assigned findings are repaired and verified locally.** The paragraph measurement and keyboard regressions failed before the production edits and pass after them.

- The actual Language Muscle introduction paragraph now follows the configured text size and typeface.
- Enter opens Listen with focus on its Close button; Escape hides it and returns focus to Listen.
- Closing and reopening during playback preserves the audio instance, playing state and position.

## Changes and ownership

The production changes are limited to `packages/reader-core/src/original/reading-support/support.css` and `packages/reader-core/src/original/PublicationReader.tsx`.

The stylesheet applies the selected size and typeface directly to body blocks, including paragraphs carrying manuscript utility classes. It retains heading selectors and excludes descendants of pre/code/kbd/samp/MathML from the added rule. It does not rewrite source content.

The reader focuses the existing Close button in an effect depending only on whether Listen is open. The panel remains mounted. Its existing Escape handler and close callback provide dismissal and trigger-focus restoration. Text preference rerenders do not rerun the focus effect. The parent's `useListeningHighlight` call and actual text-model integration remain unchanged.

The regression extension is in `scripts/check-reader-corrections.py`. Its normal run includes both new checks alongside the existing real-book checks. Its new `--closure-only` option runs these checks without creating screenshots or writing the parent's evidence JSON. The playback fixture bundles the actual reader in memory, supplies the current Language Muscle book unchanged and reuses the existing listening test's 24-second silent WAV construction. It creates no fixture files or audio assets.

This receipt is the fourth owned file. No module tests were edited. No Git commands, staging, commits, dependency changes, publication edits or network-asset changes were performed. The allowed root build regenerated the existing ignored build outputs. The historical before evidence and the parent's saved verification evidence were not rewritten.
