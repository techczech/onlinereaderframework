<td><p><strong>!</strong></p></td>
<td><p>Most of adverbs in Czech are formed from adjectives.</p>
<ul>
<li><p>The <strong><em>-ý</em></strong> or <strong><em>-í</em></strong> ending of the adjective is dropped, and <strong><em>-e</em></strong> or <strong><em>-ě</em></strong> is added. Remember that <strong>-<em>ě</em></strong> changes the consonant before it.</p></li>
<li><p>dobrý - dobře, jarní - jarně, mladý - mladě</p></li>
</ul>
<p>k <strong>></strong> c krátký <strong>></strong> krátce</p>
<p>ch <strong>></strong> š jednoduchý <strong>></strong> jednoduše</p>
<p>r <strong>></strong> ř starý <strong>></strong> staře</p>
<p>h <strong>></strong> z drahý <strong>></strong> draze</p>
<ul>
<li>The <strong><em>-cký, -ský, zký</em></strong> endings are shortened</li>
</ul>

<ul>
<li>hezký - hezky, český - česky</li>
</ul>

<ul>
<li>The <strong><em>-ý</em></strong> ending has an equivalent <strong><em>-o</em></strong> which is used for some words. Sometimes, there is a slight difference in meaning, which has to be learned with individual words in certain contexts.</li>
</ul>

<ul>
<li>daleký - daleko; dlouhý - dlouho; jasný – jasno</li>
</ul></td>
</tr>
</tbody>
</table>
